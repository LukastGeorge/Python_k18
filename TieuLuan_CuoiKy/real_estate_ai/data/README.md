# Dữ liệu đầu vào

- `raw/`: dataset King County, bản ZIP tải về và thông tin nguồn/checksum. Notebook sử dụng dữ liệu USD tại đây.
- `input/`: mẫu CSV và các file nhập cho pipeline VND. Sao chép `input_template.csv` để tạo file dữ liệu riêng; không sửa trực tiếp dataset gốc.

Database của ứng dụng nằm ở `../storage/`; mô hình sau huấn luyện nằm ở `../models/`.
