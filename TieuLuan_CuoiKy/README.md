# Tiểu luận cuối kỳ — Dự đoán giá nhà

- [Notebook nhóm 8](TeamWork_PP_Nhom8.ipynb): phân tích King County, so sánh Ridge/XGBoost và đánh giá mô hình bằng USD.
- [Ứng dụng và hướng dẫn chạy](real_estate_ai/README.md): pipeline CSV/demo, PostgreSQL hoặc SQLite, huấn luyện và dự đoán bằng VND.

Khuyến nghị Python 3.12. Chạy `real_estate_ai/cai_dat.cmd` để tạo môi trường và cài thư viện cho ứng dụng. Để chạy lại notebook, cài thêm `requirements-notebook.txt` theo hướng dẫn trong ứng dụng.

Notebook dùng dữ liệu King County đi kèm và chạy độc lập với database của ứng dụng.
